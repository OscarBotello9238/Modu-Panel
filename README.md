# Modu-Panel
Currently designing a custom sheet-metal panel to enclose the back of the Wilson Electronics workstation table. The panel features an engraved Wilson logo and a hinged access door to improve cable management, maintenance access, and overall workstation appearance
This project was designed in SolidWorks. I recently finished the design and am waiting for senior engineers to review it. Once approved, I’ll reach out to sheet metal manufacturers to get quotes for fabrication
